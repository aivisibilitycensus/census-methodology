# AI Visibility Census: methodology and question sets

The [AI Visibility Census](https://aivisibilitycensus.com) measures which firms AI answers name when buyers ask for recommendations, and which sources those answers cite. Each edition asks a fixed, published set of buyer questions across six AI engines on set dates.

This repository holds the parts anyone needs to check or repeat our work:

| File | What it is |
|---|---|
| [METHODOLOGY.md](METHODOLOGY.md) | How editions are made: what is measured, engines, questions, collection and limits |
| [questions/](questions/) | The question set for each edition, published when the edition's collection starts |
| [CHANGELOG.md](CHANGELOG.md) | Every change to the methodology, with dates |
| [LICENSE](LICENSE) | Creative Commons Attribution 4.0 International (CC BY 4.0) |

The website is the primary source. If this repository and the website ever disagree, the website wins, and we would like to hear about it.

## Status

Methodology draft published 29 October 2026. It will be finalized and dated before Edition 1, which covers professional and specialist services firms in Ireland.
